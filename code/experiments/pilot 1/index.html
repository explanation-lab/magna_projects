Current assignment and design notes
OrderCaseContextCategoryOutcome

Each walkthrough has four distinct contexts, one case from each category, and all three outcomes with one repeated. Story order is randomized. Questions always appear in the order compensatory, then punitive.

Assignments are sampled uniformly from 864 patterns. The complete set of patterns balances every context × category × outcome combination. Random sampling does not guarantee exact balance in a small sample; a deployed study will need coordinated allocation.

The participant screens use a seven-point scale, from 1 (Not at all) to 7 (Very strongly). “Plaintiff” means the party seeking an award; the company is the defendant. The case narratives are copied from the Magna Pilot document.

The consent, optional demographics, feedback form, page styling, and buttons follow the cross-cultural causal-verb pilot. This offline review does not submit responses. Review responses exist only in this open tab unless downloaded. Exported responses are marked as review data.
