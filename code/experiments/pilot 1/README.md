# Pilot 1

Double-click `index.html` to review the study offline.

`Magna_Pilot_Review.zip` contains the same `index.html` for sharing. Extract it before opening.

The reviewer panel can inspect any of the 48 case versions, walk through a randomized three-case session with one case per outcome, and export review responses. Both comprehension checks require Yes; wrong answers return to the instructions and restart both checks. No responses are submitted.
